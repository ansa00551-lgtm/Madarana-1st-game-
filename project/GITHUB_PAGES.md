# 🚀 دليل نشر التطبيق على GitHub Pages المباشر

لقد قمت بإعداد وتجهيز الكود والملفات بالكامل لتكون متوافقة بنسبة 100% مع منصة **GitHub Pages** المجانية للمواقع الثابتة.

تحتوي هذه الملفات الآن على:
1. **تعديل مسارات الأصول المتنقلة (`base: "./"`)**: لضمان عمل كافة الصور والتنسيقات وأيقونات الموقع وعناصره بشكل سليم داخل المجلدات الفرعية في GitHub بدون أي روابط مكسورة أو أخطاء 404.
2. **ملف أتمتة النشر الذكي (`.github/workflows/deploy.yml`)**: يقوم بمجرد رفع الموقع إلى جيت هاب ببناء الكود وتنشيط رابط موقعك المباشر تلقائياً!

---

## 📥 الخطوة 1: كيفية تحميل ملفات هذا المشروع من AI Studio

لتحميل نسخة كاملة ونظيفة من هذا المشروع بصيغة **ZIP**:
1. أنظر إلى الزاوية العلوية اليمنى في واجهة **Google AI Studio** المخصصة للتطوير.
2. اضغط على أيقونة الإعدادات (أيقونة **الترس ⚙️** أو زر **Export** المتوفر في واجهة التطبيق).
3. اختر خيار **"Export as ZIP" (تصدير كملف ZIP)**.
4. قم بفك الضغط عن الملف المُنزل على جهازك الشخصي في أي مجلد تريده.

---

## 🖥️ الخطوة 2: تهيئة المشروع على جهازك (اختياري)

إذا كنت ترغب في تشغيل واختبار التطبيق محلياً قبل الرفع:
1. افتح نافذة الأوامر (Terminal/CMD) في المجلد الذي فككت فيه الضغط.
2. قم بتثبيت الحزم البرمجية بكتابة الأمر:
   ```bash
   npm install
   ```
3. لتشغيل خادم التطوير للاختبار المحلي:
   ```bash
   npm run dev
   ```

---

## 🐙 الخطوة 3: إنشاء مستودع جديد على GitHub ورفع الملفات

1. اذهب إلى موقع [GitHub](https://github.com) وقم بتسجيل الدخول، ثم أنشئ مستودعاً جديداً (**New Repository**).
2. سمّ المستودع بالاسم الذي ترغب به (على سبيل المثال: `game-hardware-compatibility-analyzer`).
3. اجعل المستودع **Public** (عام) واضغط **Create Repository** (لا تقم بإضافة ملف README أو `.gitignore` أثناء الإنشاء من الموقع لأنها موجودة مسبقاً في ملفاتنا).
4. في جهازك الشخصي، افتح Terminal داخل مجلد المشروع وقم بتنفيذ الأوامر التالية لربط المشروع ورفعه:

```bash
# تهيئة مستودع جيت محلي
git init

# إضافة جميع الملفات للمستودع
git add .

# إنشاء أول التزام (Commit)
git commit -m "Initial release for GitHub Pages"

# تعديل اسم الفرع الرئيسي إلى master أو main
git branch -M main

# ربط المستودع المحلي بمستودع جيت هاب (قم باستبدال الرابط برابط مستودعك الخاص)
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git

# رفع الكود بالكامل
git push -u origin main
```

*(تذكر استبدال `YOUR_USERNAME` باسم حسابك في GitHub و `YOUR_REPO_NAME` باسم مستودعك الجديد).*

---

## ⚙️ الخطوة 4: تفعيل النشر التلقائي من إعدادات GitHub

بفضل نظام الأتمتة الذكي الذي أضفته لك (`.github/workflows/deploy.yml`)، كل ما تحتاجه هو إعلام جيت هاب باستخدام هذا الملف للنشر:

1. اذهب لصفحة مستودعك في **GitHub**.
2. من القائمة العلوية اضغط على تبويب **Settings** (الإعدادات).
3. من القائمة الجانبية اليسرى، انزل إلى قسم **Code and automation** واضغط على **Pages**.
4. تحت خيار **Build and deployment**:
   * عند خيار **Source**، قم بتغييره من `Deploy from a branch` واجعله **`GitHub Actions`**.
5. بمجرد اختيارك لقيمة **`GitHub Actions`**، افتح تبويب **Actions** من القائمة العلوية وستشاهد عملية النشر قد بدأت فورياً ومجاناً!
6. عند اكتمال البناء الأخضر، سيظهر لك الرابط المباشر لموقعك بالصيغة التالية:
   `https://USERNAME.github.io/REPO_NAME/`

## ⚡️ توافقية التشغيل مع GitHub Pages (نظام البحث والتحليل البديل)

نظرًا لأن GitHub Pages هي استضافة **ملفات ثابتة بالكامل (Static Hosting)** ولا توفر خوادم خلفية لتشغيل خادم Node/Express المدمج:
* **نظام البحث التلقائي عن الألعاب**: قمت بتضمين **3 مستويات ذكية كخط دفاع بديل**؛ في حال عدم توفر الخادم، سيتصل التطبيق مباشرة وبشكل آمن بواجهة RAWG الرسمية ووكيل Vercel السحابي الآمن مجاناً وسيجلب أي لعبة تبحث عنها، وفي حال انقطاع الإنترنت كلياً سيعمل النظام الداخلي لعرض نتائج ثابتة ذكية!
* **تقرير محاكاة الذكاء الاصطناعي**: في حال عدم المقدرة على الاتصال بمفاتيح الذكاء المعقدة، تم تضمين خوارزمية محاكاة جغرافية وهندسية قوية تقوم ببناء واحتساب تقارير التوافقية ومعدل الإطارات المتوقع (FPS) واختناقات المعالج وكرت الشاشة بدقتها العالية محلياً وتقديمها كتقرير Markdown كامل مع دقة الشاشة الموصى بها كالبديل الآمن والجاهز!
